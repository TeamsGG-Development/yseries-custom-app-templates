# YSeries | YFlip x YPhone x Boomer - Custom App Templates

### The repository contains templates for creating custom apps for the [YSeries](https://yseries.live/) phones (YPhone, YFlip) and the Boomer phone.

## Templates provided

- React + Typescript
- [Boomer phone (vanilla HTML/CSS/JS, no build)](./boomer-app-template)
- React + Javascript (soon)
- Vanilla Js (soon)

- Could add more on demand.
